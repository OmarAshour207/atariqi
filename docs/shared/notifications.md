# الإشعارات والبريد وOTP

## 1. FCM (موبايل)

الدالة: `sendNotification($data)` في `app/Helper/helpers.php`.

- المدخلات الشائعة: `title`, `body`, `tokens` (مصفوفة؛ يُستخدم العنصر الأول)  
- يعتمد `fcm_token` المخزّن على `users`  
- عند الفشل: تسجيل في Log — لا يعيد رمي استثناء دائمًا بشكل يمنع استمرار الطلب (راجع التنفيذ الحالي في الملف)

**استدعاءات نموذجية من الكود:**

| الحدث | المستلم |
|-------|---------|
| اختيار سائق يومي/أسبوعي | السائق |
| إشعار قبول/رفض يومي/أسبوعي (`getUserNotification`) | الراكب |
| قبول يومي من السائق / بدء رحلة / مجموعة | الراكب |
| `notify-driver-nearby-trips` | السائق (قرب موعد الانطلاق) |
| `HomeController@test` | توكن ثابت للاختبار |

لا يوجد مجلد `app/Notifications`.

## 2. OTP / SMS

- Trait: `GuardsOtpSending`  
- حد معدل + رفض غير سعودي  
- التسليم عبر `deliver_otp_code` (helper) — قنوات Twilio/Vonage حسب الإعداد  
- `OtpBypass` لأرقام اختبار  

مسارات: تسجيل/إرسال/تحقق راكب؛ دخول/تحقق سائق.

---

## 3. البريد الإلكتروني (`app/Mail/`)

أمثلة مرتبطة بالتشغيل:

| Mailable | متى |
|----------|-----|
| باقات جديدة/تحديث/حذف | داشبورد Packages → سائقون |
| تعيين/إلغاء باقة | داشبورد سائق |
| تذكير دفع | داشبورد أو أمر `payment-reminder` |
| قبول/رفض/حظر سائق أو راكب | داشبورد |
| تذاكر الدعم | رد/إسناد/إغلاق |
| تحديث مستند | لجميع المستخدمين ذوي إيميل |
| محاولة دخول غير مصرح | `LoginThrottle` → أدمن |

كثير من الإرسالات تُسجَّل في `PlatformEmailLog`.
